## `nixpkgs` PR tracker

A CLI-based tool to track PRs as they traverse Nix(pkgs) channels. This tool was
written in record time by supplementing with generative AI, which you can read
more about in detail in [this blog post](/posts/using-gen-ai-for-development)!

- Written in Go for cross-platform support
- Exposes a package flake for easy import to your own flake
- Support for modern terminal features like hyperlinks
